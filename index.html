🛠️ Behind the Build: Engineering & Decisions

Welcome to the lab archives! This portfolio was built with a strict philosophy: Zero heavy bloated frameworks, zero external tracking, instant 300ms feedback, and 100% accessible fallbacks.

The Core Stack:

Semantic HTML5 CSS Custom Properties (Live-Tinting) Modular ES6+ JavaScript HTML5 2D Canvas (Particles & MRI) Pure Web Audio API Synthesizer LocalStorage Telemetry

What Broke & What I Learned:

1. Physics vs Framerate: Heavy particle physics drained mobile battery. I capped mobile particles to 50, throttled canvas redraws on blur, and connected automatic degradation if FPS dips below 45.
2. Audio Ethics: Web Audio is powerful but obnoxious if forced. Kept sound 100% opt-in, synthesized procedurally without loading external MP3 files.
3. Vibe Coding Reality: When building InvoiceWise and Vellum, orchestrating complex state machines without bloat taught me how to architect clean software contracts.

— Siddharth Gupta (Bennett University '26)
